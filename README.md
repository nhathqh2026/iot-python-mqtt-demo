# IT4735 — MQTT Data Exchange Demo (Python)

A minimal Smart Greenhouse example using **Eclipse Paho MQTT Python** and an existing MQTT Broker (local Eclipse Mosquitto or HiveMQ Public). The example is designed for a lecture on MQTT Publish/Subscribe.

## 1. Architecture

```text
Sensor Publisher (publisher.py)
        |  PUBLISH: greenhouse/area/1/light
        v
  MQTT Broker (Mosquitto or HiveMQ Public)
        |  forwards matching PUBLISH
        v
Viewer Subscriber (subscriber.py)
   SUBSCRIBE: greenhouse/area/+/light
```

- Publisher: simulates a sensor. Every 5 seconds, it sends a random lux reading with `timestamp`, `area`, and `lux` as JSON.
- Broker: receives PUBLISH messages and routes them according to subscriptions. **The Broker is not coded in Python**.
- Subscriber: registers a Topic Filter and displays matching JSON measurements in its `on_message` callback.
- This introductory demo uses MQTT **3.1.1, QoS 0, retain=False**; it does not store message history or CSV files.

Example payload (actual timestamp is generated by the Publisher):

```json
{"timestamp":"2025-05-02 05:44:35","area":1,"lux":500}
```

## 2. Requirements

- Windows 10/11, macOS, or Linux with **Python 3.9 or later**.
- Internet for installing Python packages (and for using HiveMQ Public).
- **One Broker option:** Eclipse Mosquitto installed locally, **or** the public HiveMQ Broker.

Install Python dependencies in PowerShell, from this project folder:

```powershell
python -m pip install -r requirements.txt
```

## 3. Broker configuration (edit `config.py`)

### Option A — Mosquitto on the same laptop (default)

```python
BROKER_HOST = "127.0.0.1"
BROKER_PORT = 1883
TOPIC_ROOT = "greenhouse"
```

Download Mosquitto from <https://mosquitto.org/download/>. When installed on Windows, you can start the broker in a terminal if it is not already running as a Windows service:

```powershell
& "C:\Program Files\mosquitto\mosquitto.exe" -v
```

Recent Mosquitto versions support local-only access without creating a separate config file. If port 1883 is already in use, Mosquitto may be running as a Windows service: do not start a second instance.

### Option B — HiveMQ Public Broker (no local broker install)

Change the settings in **the same `config.py` shared by both Clients**:

```python
BROKER_HOST = "broker.hivemq.com"
BROKER_PORT = 1883
TOPIC_ROOT = "it4735/demo/your-unique-id/greenhouse"
```

**Replace `your-unique-id` with a unique identifier**. The public broker is intended for tests, not guaranteed production availability.

## 4. Run the full demo

Use **two terminals** after setting `config.py` and ensuring the Broker is available.

**Terminal 1 — Start the Subscriber first:**

```powershell
python subscriber.py
```

Expected startup (localhost option):

```text
[BROKER] 127.0.0.1:1883
[FILTER] greenhouse/area/+/light
[INFO] Waiting for measurements... Press Ctrl+C to stop.
[SUBSCRIBE] greenhouse/area/+/light (QoS 0)
```

**Terminal 2 — Start the Publisher:**

```powershell
python publisher.py
```

Publisher example:

```text
[CONNECTED] MQTT Broker accepted the connection
[PUBLISH] greenhouse/area/1/light -> {"timestamp":"2025-05-02 05:44:35","area":1,"lux":500}
```

The Subscriber prints something like:

```text
[RECEIVED] timestamp=2025-05-02 05:44:35 | area=1 | lux=500 | topic=greenhouse/area/1/light
```

The displayed timestamp and lux will differ on each run. Stop either process with **Ctrl+C**.

## 5. Demonstrate multiple Publishers and wildcard subscriptions

The following optional arguments **do not need to be supplied** for the default demo; edit constants in `config.py` if you prefer working only in VS Code.

Start a Subscriber for **light measurements from all areas**:

```powershell
python subscriber.py --filter "greenhouse/area/+/light"
```

Start two independent Publishers in separate terminals:

```powershell
python publisher.py --area 1
python publisher.py --area 2
```

Both areas should appear in the Subscriber's output. To receive **everything under area 1**:

```powershell
python subscriber.py --filter "greenhouse/area/1/#"
```

To send only five measurements (useful for a brief demo):

```powershell
python publisher.py --area 1 --count 5
```

**If using HiveMQ Public**, prefix each filter in these examples with the same `TOPIC_ROOT` as `config.py`, or simply run `subscriber.py` with no `--filter` argument.
